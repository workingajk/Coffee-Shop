# Coffee Shop Website

A static coffee-shop landing page built with HTML and CSS. The page presents coffee products, category highlights, service offerings, location details, and social links.

## Tech Stack
- HTML5
- CSS3
- Font Awesome icons

## Run Locally
1. Clone or download this repository.
2. Open `index.html` in a web browser.

No build step is required. Images are stored in `img/`, while some product images and icons are loaded from external URLs.

## Project Structure
- `index.html` — page content and sections
- `style.css` — layout and styling
- `img/` — local image assets
